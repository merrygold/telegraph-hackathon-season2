How one paid answer works
  1. The agent asks. It sends a question to the Telegraph network, such as "hashprice at block 975340".
  2. The network names a price. It replies "payment required": one cent of test USDC.
  3. The agent's wallet signs. No person clicks anything, and you never connect a wallet of your own.
  4. Answer and receipt come back. Each one links to the public record of that payment.

Three entries, one idea

About.

Many contracts say "pay if a number crosses a line": if hashprice drops under a floor, if a port keeps ships waiting more than 48 hours, if a coin loses its peg. Today a person checks the number. Tripwire is an agent that buys the number, checks it a second way, and records the decision with a receipt for every answer. Everything here runs on a test network with test money.

How one cover is settled

  1. Read the wording. Paste a sentence such as "Pays if the price of ETH falls below 1,500 US dollars." Fixed rules, not a model, find the number, the line and the unit, so anyone can audit what will trigger a payout. It is free.
  2. Buy the number. The agent asks one Telegraph miner for the measured value and pays one cent in test USDC through x402: the miner asks for payment, the agent's wallet signs, the answer comes back with a receipt. You watch each of those steps on the Settle tab.
  3. Check it a second way. If the first answer crosses the line (or always, if you tick the box), the agent buys the same number from a different, independent miner. A miner is never asked twice.
  4. Decide. Pay only when both answers agree within the cover's tolerance and both are past the line. No payout when they are not. Disputed when the miners disagree, or fall on opposite sides of the line, so a coin flip never moves money. No data when nobody answers.
  5. Record. Every decision keeps the answers, miner names, payment transactions and a link to the stored answer on the network. On a Pay, a cover can also send a small test-USDC payout; it is limited to a set amount, once per cover, and only for covers stored on the server.

The three entries

01 Tripwire (app). This page. Six kinds of cover: Bitcoin hashprice, waiting time at a Finnish port, air temperature at a place, the price of any coin, a stablecoin losing its peg, and what one US dollar buys in euros. A scheduled check can also run them without a person.

02 Gauge (miner). A service registered on the network that answers those same five questions. Each answer comes from two free public sources and is refused, with an error instead of a guess, when they disagree. Tripwire uses it as one of its second opinions, and says so openly: the app and Gauge are paid to and from one wallet.

03 Tripwire Measure (evaluator). A tiny scoring program that rates a miner's answer against the true value, from 0 to 10,000, plus a benchmark of real paid answers. It showed that the network's own routing sometimes sends a request to a miner that scores zero. The network cannot yet run it live for this kind of question (a known open issue on their side), so this entry rests on the benchmark and a truth source that has been uploaded.

What this is not

It is not insurance and moves no real money. Cover that pays on weather is not new: earlier entrants built it. What is different here is the range of triggers, the plain-wording reader, and the habit of buying a second answer before money moves. In practice that second answer matters: on one check the same port was reported as 965 hours by one miner and 0.06 hours by another, and a single answer would have paid a 48-hour delay cover wrongly. The Ledger tab lists every such disagreement.

Where things stand

DoneApp

All six cover types settled with real paid answers. Live stage-by-stage view, wording reader, cross-check against Gauge, permanent link for each decision, and totals that separate checks started by a person from scheduled ones.

DoneMiner

Gauge is registered and active on the network, answering five questions, with real answers bought from it through the network. It re-registered at its current address after the first host was lost; the network ranks a new miner only after a 7-day waiting period, so ranking starts around 23 November.

DoneEvaluator

The scoring program matches its reference rule on 12,444 test cases. Benchmark published. Truth source uploaded and admitted to the network's evaluation pool.

WaitingFirst payout

The payout is switched on, but only the hashprice floor cover has one, and its first settlement was Disputed because the miner the network picked answered 22% high. It pays the moment two miners agree on a breach. Until then no payout has been sent, so none is claimed.

WaitingIndependent use

Few people other than the builder have tried it so far. Try a cover and the Ledger tab will show it as started by a person.

OpenLimits

The evaluator cannot go live on the network yet (their issue, not ours). Port waiting time covers Finnish ports only, because that is the one free source with both port calls and ship positions. The temperature comes from weather models, not a weather station. Several miners the network lists are down, so covers name miners that were checked alive. The payout is a plain transfer, not an escrow contract.
