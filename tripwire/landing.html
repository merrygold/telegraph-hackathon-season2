Cover that buys its own proof.

Parametric cover pays when a number crosses a line — and the weak point is whoever supplies the number. Tripwire reads the trigger sentence with fixed rules, pays one cent for the measured value on the Telegraph network, buys the same number a second time from a different miner, and only then decides: PAY, NO_PAY, DISPUTED or NO_DATA — with a receipt for every answer.

How it works

No loss adjuster. Two purchased answers and a rule.

A cover is a sentence: "pays if hashprice drops under 45,000". Tripwire turns that sentence into evidence it bought itself, then applies the rule. Nothing is graded on trust and nobody is asked to believe a single feed.

01

Read the wording

Fixed rules — not a model — find the number, the line and the unit, so anyone can audit what triggers a payout. Free.

02

Buy the number

x402: the miner asks for payment, the agent's wallet signs, the answer returns with a receipt. About one cent.

03

Check it twice

If the line is crossed, the same number is bought from a second, independent miner. A miner is never asked twice.

04

Decide by rule

PAY only when both agree within tolerance. Disagree, and the verdict is DISPUTED — a coin flip never moves money.

05

Record everything

Answers, miner names, payment transactions, a permanent link per decision. A watch loop re-checks on a timer.

Read the fine print

What this is, plainly.

Everything here is honest about its limits. The short version:

※Testnet only. Ethereum Sepolia, test USDC and test ETH. No real money moves anywhere, and the app never asks you to connect a wallet.
※One shared wallet, disclosed. The app pays from and Gauge is paid into the same test wallet, so the second answer often comes from our own miner. The first answer always comes from another operator's miner.
※The evaluator is not live on the network. The node currently classes this question family as judgment (open issue #171 on their side). The entry rests on the 12,444-case check, the benchmark and an uploaded, admitted truth source.
※Port cover is Finnish ports only. Fintraffic is the one free feed with both port calls and ship positions. Gauge says so plainly when asked about Rotterdam.
※Weather cover is not new. Three Season I entries built it. The range of triggers, the plain-wording reader and the bought-twice habit are the point here.
※The payout is a plain transfer. A cover on file can carry a small test-USDC payout — capped, once per cover, only when both miners agree. It is not an escrow contract.
