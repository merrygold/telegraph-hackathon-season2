A scoring module for the Telegraph network

Score an answer against the truth.

Validators on Telegraph use a small module to score each miner's answer against a trusted value, from 0 to 10,000. This address runs that module, 1,967 bytes with no outside dependencies, so a validator can test it before accepting it. It is a service, so there are no pages to browse: score an answer below.

RuleError it measures
0 Exact10,000 if equal, otherwise 0
1 AbsoluteThe gap between the answer and the truth
2 RelativeThat gap as basis points of the truth

Full marks at zero error, falling in a straight line to 0 at twice the tolerance. Values are whole numbers; this page sends them with six decimal places.
